# تقرير صيانة وتنظيف المستودع

**التاريخ:** 2026-10-10، مع تحديث وصف الاستضافة في 2026-10-11
**المشروع:** Élan Scents
**الهدف:** تبسيط التشغيل وتقليل التكرار دون تغيير سلوك المتجر أو قاعدة البيانات.

## بنية التشغيل الحالية

- `api/config.js` هو endpoint إعداد Supabase الذي تستخدمه صفحات المتجر والحساب ومحرر الموقع.
- `railway/server.js` هو خادم الموقع الوحيد، ويقدّم الملفات الثابتة وواجهات `/api/*` مع قواعد التوجيه والكاش مباشرة.
- `package.json` يحدد `npm start` لتشغيل خادم Railway و`npm test` لتشغيل الاختبارات.
- `.gitignore` يحمي ملفات البيئة المحلية والأسرار وملفات الأدوات والسجلات من الرفع بالخطأ.

## ملفات الواجهة التي تبقى منفصلة عمدًا

- `style.css` و`style-3.css`: ملف أساسي وملف تعديلات فوقه.
- `app.js` و`app-core.js`: طبقة واجهة وتوافق فوق نواة التطبيق.
- ملفات API واللوحات واختبارات migrations مطلوبة للتشغيل أو التحقق.
- الصور والفيديو والخطوط أصول تشغيلية للواجهة.

## التحقق

```bash
npm test
```

تُسجل نتيجة الاختبارات بحسب آخر تشغيل محلي أو GitHub Actions، ولا تُعد بحد ذاتها إثباتًا لنشر Railway. يحمي خادم Railway ملفات المصدر والإدارة والاختبارات والبيانات الداخلية من التقديم العام.
