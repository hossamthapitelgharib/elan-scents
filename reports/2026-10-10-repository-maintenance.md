# تقرير صيانة وتنظيف المستودع

**التاريخ:** 2026-10-10  
**المشروع:** Élan Scents  
**الهدف:** تبسيط الدفع والنشر وتقليل التكرار دون تغيير سلوك المتجر أو قاعدة البيانات.

## ما تم تنظيفه

- حذف النسخة المكررة غير المستخدمة `config.js` من الجذر.
- حذف النسخة المكررة غير المستخدمة `src/api/config.js`.
- الإبقاء على `api/config.js` باعتبارها endpoint الإعدادات الوحيد المستخدم من:
  - Railway.
  - Vercel.
  - صفحات المتجر والحساب ولوحة المحرر.
- إضافة `.gitignore` لحماية مفاتيح البيئة والملفات المحلية وملفات الأدوات والسجلات من الرفع بالخطأ.
- تحديث `README.md` ليشرح البنية الفعلية، أوامر التشغيل، Railway، Vercel، Supabase، والاختبارات.
- إضافة أمر تشغيل موحد:

```bash
npm start
```

ويشغّل:

```bash
node railway/server.js
```

## ما لم يتم حذفه عمدًا

- `style.css` و`style-3.css`: ملف أساسي وملف overrides، وليسا تكرارًا.
- `app.js` و`app-core.js`: طبقتان مقصودتان؛ الواجهة والتوافق فوق النواة المستقرة.
- ملفات API واللوحات والاختبارات وملفات migrations: مستخدمة أو مطلوبة للنشر والاختبار.
- ملفات الصور والفيديو والخطوط: أصول تشغيلية للواجهة.
